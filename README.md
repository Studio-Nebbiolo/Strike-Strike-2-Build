## CROWNWORKS 협동 PvE

게임 시작 → 방 만들기 → **PvE · 크라운웍스 원정** → 원정 시작.

1–4명이 루팅과 성장을 거쳐 킹핀 보스에 도전합니다. 혼자서도 시작할 수 있습니다. 온라인 협동은 같은 게임 서버에 연결해야 합니다.

- E 길게: 루팅·동료 구조·보급·보스 활성화.
- 남쪽 작업대에서 U / I / O: 공격·도탄·생존 강화.
- 성장은 한 원정 동안 유지됩니다.

## 기존 PvP

대기실에서 Bankshot / Dust2 선택 → 봇 추가 → 게임 시작.
방장이 맵을 바꿔도 방 코드와 참가자·개별 봇 난이도가 유지됩니다. 1–24라운드를 설정할 수 있습니다.
비대칭 A·미드·B 맵, 램프·도탄 전투, 타격음·피격 효과와 UI 개선을 포함하며 기존 Dust2도 유지합니다.
