# Strike-Strike 2 — Windows 테스트 빌드

## 최신 버전: BANKSHOT · 2026-09-22

[최신 Windows 빌드 다운로드](https://github.com/Studio-Nebbiolo/Strike-Strike-2-Build/releases/tag/bankshot-2026-09-22)

릴리스의 Assets에서 ZIP을 내려받아 **전체 압축 해제 후 `StrikeStrike2.exe`를 실행**하세요. Unity Editor와 Node.js를 따로 설치할 필요가 없습니다. EXE와 함께 들어 있는 폴더와 DLL을 유지해야 합니다.

**게임 시작 → BANKSHOT → 방 만들기**에서 봇과 테스트할 수 있습니다. 기존 Dust2도 같은 화면에서 선택할 수 있습니다.

BANKSHOT은 볼링공의 도탄과 램프 전투를 위해 설계한 신규 맵입니다. 이 저장소는 테스트 빌드를 배포하며, 정식 Steam 출시 버전은 아닙니다.
