# Strike-Strike 2 Build

Strike-Strike 2의 Windows 64비트 Unity 테스트 빌드 배포 저장소입니다.

## 다운로드 및 실행

1. [테스트 빌드 다운로드](https://github.com/Studio-Nebbiolo/Strike-Strike-2-Build/releases/tag/unity-test-2026-09-21)에서 ZIP 파일을 다운로드합니다.
2. ZIP **전체를 압축 해제**합니다.
3. `StrikeStrike2.exe`를 실행합니다.
4. 이름 입력 → 방 만들기 → 양 팀에 봇 추가 → 게임 시작.

Unity나 Node.js를 별도로 설치할 필요가 없습니다. Windows 10/11 64비트용이며 게임 데이터와 내장 서버가 포함되어 있습니다. EXE와 동봉 폴더를 함께 유지하세요.

조작: WASD 이동 / 마우스 좌클릭 공 굴리기 / B 상점 / R 재장전 / Space 점프 / Tab 점수판 / Esc 메뉴.

로컬 작업본으로 만든 테스트 빌드입니다. 개발 테스트용 Steam 앱 ID 480 설정이 포함되어 있습니다. 상세 변경 내역은 릴리스 페이지와 ZIP 안의 `README-KO.txt`를 참고하세요.
